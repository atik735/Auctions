🖼️ Auction Gallery
The Auction Gallery is a responsive web application built with React that displays a collection of auctionable items in a gallery format. Designed with a focus on clean UI and interactivity, it allows users to view item details, images, and bidding status in an engaging way.

🚀 Features
Built using React for a fast and dynamic user experience

Responsive grid layout powered by Tailwind CSS

Each auction card shows image, title, price, and status

Modular component structure for easy scalability

Clean and modern UI

🛠️ Technologies Used
React

Tailwind CSS

JavaScript (ES6+)

DaisyUI
